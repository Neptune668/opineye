# 完整主题分析案例：MCP 协议发布

> 本文演示从「主题检索 → 内容分析 → 报告生成 → 图谱查看」的完整链路。

## 1. 案例背景

以「MCP 协议发布」为主题，演示舆情分析平台从公开信息（news）、多媒体内容（image/video）、论坛帖子（forum_post）、内部沉淀数据（internal_data）四个方向并行收集信息，汇总生成结构化舆情报告与关系图谱。

## 2. 检索请求

通过 `POST /api/search` 发起主题检索：

```json
{
  "query": "MCP 协议发布",
  "source_types": ["news", "image", "video", "forum_post", "internal_data"]
}
```

## 3. 采集结果

三方向并行采集，共获取 15 条来源条目：

| 来源类型 | 方向 | 条目数 |
| -------- | ---- | ------ |
| news | 公开信息 | 3 |
| image | 多媒体 | 3 |
| video | 多媒体 | 3 |
| forum_post | 论坛 | 3 |
| internal_data | 内部沉淀数据 | 3 |

## 4. 情绪分析

基于规则词典（rule_based）进行情绪三分类：

| 情绪 | 条数 |
| ---- | ---- |
| 正向 | 9 |
| 中性 | 2 |
| 负向 | 4 |

**整体判断：正向**

## 5. 分析报告（8 段式摘要）

完整报告见 `backend/examples/mcp_20260826090000/report.md`，八段结构如下：

1. **事件概述**：MCP 协议发布，覆盖 5 类来源、15 条条目
2. **时间线**：08:50 首条新闻 → 09:05 内部评估报告
3. **传播渠道**：5 类来源各 3 条，分布均衡
4. **主要观点**：媒体/用户正面为主，论坛存在分歧，内部关注安全
5. **情绪倾向**：整体正向（9 正 / 2 中 / 4 负）
6. **风险判断**：安全风险与迁移成本是主要关注点
7. **重点证据**：媒体报道、内部评估、论坛讨论（带来源引用）
8. **结论摘要**：传播态势良好，需关注安全风险

## 6. 关系图谱

图谱数据见 `backend/examples/mcp_20260826090000/graph.json`：

- 中心节点：`MCP 协议发布`（topic 类型）
- 叶子节点：各来源条目（source/event 类型）
- 关系：`sourced_from`（来源引用）

在前端「图谱查看」页可查看力导向布局图谱，点击节点查看详情与来源引用。

## 7. 演示步骤

1. 启动后端：`cd backend && python run.py`
2. 启动前端：`cd frontend && npm run dev`
3. 打开控制台，发起主题检索（输入"MCP 协议发布"）
4. 查看生成的 8 段式报告
5. 进入「图谱查看」页查看关系图谱
6. 在「论坛监控」页启动采集，观察实时日志
